# 🚀 Smart WiFi Assistant

> A modern AI-powered broadband self-service web application that helps users manage their internet connection, monitor usage, renew packages, pay bills, and troubleshoot common WiFi issues without contacting customer support.

---

 Live Demo

Live URL:** https://smart-ix3m.vercel.app/

 Problem Statement

Many broadband customers face common issues every day, such as:

- Not knowing when their internet package will expire.
- Difficulty checking internet usage.
- Confusion about available packages and pricing.
- Having to call customer support for simple tasks.
- Slow response when reporting internet problems.
- No single platform to manage all broadband services.

These problems waste time for both customers and Internet Service Providers (ISPs).

---

💡 Solution

Smart WiFi Assistant is a customer self-service platform that allows users to manage almost every aspect of their broadband connection from one dashboard.

The application provides a modern interface where customers can:

- Monitor internet status
- View package information
- Track package expiry
- View bills
- Pay bills
- Test internet speed
- Check connected devices
- Contact support
- Receive notifications
- Get AI-powered assistance

This reduces dependency on customer support while improving user experience.

🤖 AI WiFi Assistant

The application includes an AI-powered assistant that helps users by answering common broadband-related questions.

Examples:

- When will my package expire?
- Why is my internet slow?
- How can I restart my router?
- Which package is best for me?
- How do I pay my bill?

The AI provides simple, step-by-step guidance to reduce the need for customer support.

---

🧠 AI System Prompt

The AI assistant was designed with the following behavior:

> You are Smart WiFi Assistant, an intelligent broadband support assistant. Help users understand their internet packages, billing, internet speed, router information, troubleshooting steps, and account management. Always provide friendly, simple, and step-by-step responses. If a problem requires ISP intervention, politely advise the user to contact support.
